# Decision and pre-commitment

> English translation of [SKILL.md](SKILL.md). Hosts load `SKILL.md`; this file is the full English body.

First read the [decision loop](../george-mode/references/decision-loop.md). Important new cases run its 11 analysis modules; filling in a form does not replace analysis. When a project requires full coverage, state applicability, unknowns and reasons module by module; ticking boxes does not replace analysis.

Separate values, goals, governance boundaries, world model and action plans. State who decides, what outcome is pursued, available time/cash, consequences that cannot be borne, and what the user has already decided. Compare feasible routes and the status quo; never pass off a route the AI prefers as the user's choice.

Write mechanism hypotheses as statements that observation could overturn. Register metrics, data window, baseline, main probability p and reference p0, due time, stop rules and review checkpoints. Plans not adopted by the user are labeled suggestions. Routine sub-actions of an already settled strategy cite the original registration and register only the real increment.

In projects that require pre-freezing, freeze before executing; if it already happened, it can only be recorded after the fact—never forge a prior prediction. If freezing fails, solve the archiving problem first and do not execute actions that depend on that commitment.

Execution goes to [george-deliver](../george-deliver/SKILL.md); when due or a stop condition triggers, go to [george-reflect](../george-reflect/SKILL.md).
