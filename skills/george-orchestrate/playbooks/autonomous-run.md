# 单任务持续执行

1. 把done写成真实可检查谓词，同时确定预算、停止/回退规则、授权及必须保存的证据。不能只以“工作多久”为结束条件。
2. 有事件用宿主事件等待，无事件按结果变化速度退避检查；当前会话可以继续运行。用户明确要求以后/持续监控时才创建宿主原生自动化，不能用隐藏shell替代调度。
3. 每轮最小有证据改动→真实检查→保留有效改动或撤销失败尝试→追加decisions。可以委派独立产物，负责人核验。
4. 范围内阻碍自行解决；无关改进记录不扩大任务，必要独立修复保持可审。失败先追根因，平台结果未知先对账。
5. 阶段完成、目标达到、预算/停止条件触发、真实不可继续时报告实际状态。平台期换思路，不降低谓词换通过；不无限消耗。
6. 最终实际验收、状态核对与干净检查点，清理本任务监控。
