# 调查、设计和审查

先读 [接入合同](../george-mode/references/integration.md)，按实际问题选择：

| 场景 | 工作流 |
|---|---|
| 如何运行/历史原因/给读者解释 | [how与why](workflows/how-why.md) |
| 只读理解或建议 | [调查](playbooks/investigation.md) |
| 架构取舍/多方案/代码竞赛 | [architect与arena](workflows/architect-arena.md) |
| 可实验的布局/行为分歧 | [prototype](playbooks/prototype.md) |
| 独立评审、争议、安全与机器人发现 | [interrogate](workflows/interrogate.md) |
| 小改动的外部影响、复述/提高任务质量 | [blast-radius](workflows/blast-radius.md) |

结构上不同的候选、相同标准、独立评审与合成后验证构成完整设计能力。简单修改按相关部分执行。重大现实取舍进入 [george-decide](../george-decide/SKILL.md)，已授权实现选定后直接推进；仅方案请求交付方案结束。
