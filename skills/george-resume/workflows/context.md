# 续接、回顾与解释

Session pickup恢复一个任务；recall重建本轮指定主题的多会话背景；ketchup只解释用户上次参与后当前任务变化；bro/teach将既有结果讲清楚。不要混用范围。

读取先元信息/最后消息/关键决定，再按需向前；长记录按已授权分片抽取。输出人类原话、Agent推断、真实工具结果各自身份与时间，不把摘要当事实最终来源。

检查当前工作区、分支、未提交改动、用户后续修正、进程与平台状态，保留尚有效证据；只有漂移、失败或缺失才补验，不从头重复。

回顾回复包含结果、变化、实际阻塞和下一可行动项；每个需要用户决定的项给足上下文。简单解释不自动恢复后台执行。
