# 续接与交接

用户指定子目录时，该子目录就是本轮任务根；不能因缺源码或同级还有项目就扩大到父目录/兄弟目录。读取明确给出的技能源不会改变任务根。恢复说明原样保留授权路径。

先找原始请求、后续修正、当前权威文件和最后一个已验证节点。最新消息通常调整当前任务，除非用户明确取消或替换目标。旧摘要与现场冲突时核查原始证据。

保存最小检查点：目标、范围与授权、已完成及证据、未完成项、修改文件、运行任务、unknown 外部操作、下一可执行动作与停止条件。涉及凭据只记获取方式，不复制秘密。

恢复时先检查现场是否变化，尤其分支、用户编辑、平台对象与运行进程。不要从头重复已验证动作，也不要把未结束的任务标成完成。被用户接管的 UI 不抢回控制。

并行任务提供明确文件所有权、源路径、验收标准和回报格式。主代理核验结果并统一写共享状态；证据同源的两个子 Agent 结论不算两份独立证据。模型沿用当前宿主允许的设置，不照抄历史模型名称或替用户改配置。
