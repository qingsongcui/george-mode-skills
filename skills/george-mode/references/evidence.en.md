# Actionable principles, confidence and boundaries

The following principles are distilled from the method specification and feedback from the author's long-term use. Original sessions and personal data are not distributed with the package; these principles do not claim universal validity, and the user's current instructions always take precedence.

| ID | Trigger and behavior | Boundary | Where it lands |
|---|---|---|---|
| G01 | Understand/check the current state first: read authoritative entry points, stay read-only | Does not override an explicit implementation request | investigate |
| G02 | Authorized and unblocked: carry through to the specified result, don't stop at dossiers and plans | Limited by "read-only / plan only" requests | deliver |
| G03 | Acceptance: choose checks that prove actual behavior | Not every task needs a browser or screenshots | verify |
| G04 | Clear delivery scope: don't expand the topic, don't swap the artifact | When the user only wants a plan, don't change code | mode, deliver |
| G05 | New observations: update the fact model, keep unknowns | A single observation counts only as single corroboration | investigate, reflect |
| G06 | Complex real-world decisions: mechanism, falsifiers, candidates and stop conditions all present | A method specification, not a verified law of success | decide |
| G07 | Unknown external platform result: reconcile before deciding whether to retry | Limited to operations with external side effects | verify, resume |
| G08 | Process too long: remove steps that cannot change the result | Full analysis tasks must not cut corners | mode |
| G09 | Adapting a reference: keep the features of the reference the user specified | Original-work requests are a separate matter | deliver |
| G10 | Multiple hosts: verify discovery, actual invocation and output separately | Copying files is not acceptance | verify, hosts |
| G11 | Same-source / copies / agent prompts: deduplicate and state source identity | Agent restatements are not independent user evidence | investigate |
| G12 | Distilling experience: candidate first, then test; keep counterexamples and versions | Does not claim existing behavioral gains | reflect |

## What is not promoted

No fixed model brands, agent positions, uniform answer lengths, uniform test counts or screenshots every time; no turning one project's business strategy into a cross-project iron rule; no requiring every task to have a full audit or parallel multi-agent work.
