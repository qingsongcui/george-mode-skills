# 理论定位与适用边界

george-mode 的决策方法完整写在 [决策闭环](decision-loop.md)，执行与验收底线写在 [先验证、后交付](verify-before-deliver.md)。二者自包含，不需要任何外部理论文件、业务台账或作者私有资料。

## 方法到执行的映射

| 方法部分 | 在技能中的作用 |
|---|---|
| 世界与约束 | 查现状和变化，拒绝用旧状态替代现场 |
| 主体、价值与互动 | 区分目标、资源、能力、授权和他方反应 |
| 证据与因果 | 追原始来源，同源去重，保留竞争解释和反证 |
| 杠杆、行动与风险 | 比较基准、替代方案、信息价值、可逆性及停止条件 |
| 测量、反馈与演化 | 明确口径，真实回读，分层归因和更新 |
| 治理与 AI | 人的责任、规则边界、AI 推断和授权分开 |

## 文件架构

保留“分析 → 方案与事前预测 → 执行与观察 → 复盘与更新 → 有边界的规则”这一逻辑。具体文件名、编号和归档方式由当前项目自己的规则决定；没有项目规则时不创建额外台账。

方法来源、个人经验和任务工作区是三个不同概念。使用本方法不意味着继承任何项目的目标、预算、平台规则或阈值。
