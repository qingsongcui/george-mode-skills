# 先减后加（Subtract Before You Add）

演进系统时，先去除复杂度，再构建。默认做减法。

把简化当作持续投资。离开时让设计比你接手时稍微更简单、更有能力，而表面积相同或更小。

- 先安排删除，再安排构建
- 先削减再打磨（先达到最小，再投入质量）
- 为观察到的使用方式设计，而不是为猜测的边界情况设计
- 不加规格要求之外的投机性校验器、解析器或守卫
- 简化提示词（删除冗余指令、过多的模板）
- 当一份参考没有新内容时，删除它，而不是留下一个空壳

## George 适用边界

按触发场景应用；结果有证据、适用边界和反例。重要现实决策接理论闭环，普通工程不强制全套经营记账。
